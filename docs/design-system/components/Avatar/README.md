# Avatar

Initials on the student's color tag; there are no photos in Tutora.

## Consumer provides
`initials` (two letters, first and last name), `tag` (the student's color: amber, green, blue, violet, orange, red, teal), `size` sm 36 / md 44 / lg 48.

## Rules
- The tag is chosen when the student is created (next unused color) and reused everywhere: avatar, dots, agenda blocks, report rows.
- Decorative for screen readers: the name next to it is the label.
